# 🎬 Movie Explorer

Movie Explorer is a React-based movie and TV series browsing application built using the TVMaze API.

## ✨ Features

- 🎬 Browse movies and TV shows
- 🔍 Search movies and TV series
- ⭐ Display ratings
- 📅 Display release year
- 🖼️ Movie posters
- 📖 View movie details
- 📱 Responsive design
- 🧭 React Router navigation

## 🛠️ Technologies Used

- React.js
- JavaScript
- React Router DOM
- Tailwind CSS
- Vite
- TVMaze API
